# Changelog

All notable changes to Kivrio Chat are documented in this file.

## [Kivrio Chat 2026.5.28] - 2026-05-28

### Added
- Added dedicated actions for standalone HTML code blocks generated by the model: copy raw HTML, open a sandboxed local preview, and download a `.html` file.
- Added a focused render test to confirm the HTML actions appear only on HTML code blocks.

### Changed
- Raised the Web Search query length limit from 400 to 800 characters and aligned the backend security test with the new boundary.
- Improved live answer display after long reasoning so the interface reveals the first answer without continuously forcing the scroll to the bottom of the growing message.
- Reset the composer textarea height after sending a long prompt so the input returns to one line for the next prompt.
- Updated `README.md` for `Kivrio Chat 2026.5.28`.

### Tested
- Passed the focused HTML code action render test.
- Passed the local backend safety net covering persistence, upload limits, server security, PDF extraction, error UX, sidebar search, HTML code actions, Ollama abort, Web Search prompt injection, Web Search sources, and PDF upload preparation.

### Removed
- Removed the local authentication record from the working tree so the user password is not kept locally or tracked.
- Confirmed the active local database remains outside GitHub and temporary upload, voice, and SearXNG runtime directories are clean.
- Confirmed third-party runtime/vendor payloads, including Whisper, SearXNG, KaTeX, Python runtime files, local models, and PDF libraries, remain out of GitHub.

## [Kivrio Chat 2026.5.25] - 2026-05-25

### Changed
- Hardened Markdown/KaTeX rendering by escaping preserved math tokens before reinserting them into rendered message HTML.
- Made the managed SearXNG launcher timeout effective by collecting process output asynchronously instead of blocking before timeout handling.
- Stabilized the immediate Stop flow after sending: if generation is stopped before the user message is persisted, the transient user bubble is removed and the prompt input plus pending attachments are restored safely.
- Updated `README.md` for `Kivrio Chat 2026.5.25`.

### Tested
- Passed the local backend safety net covering persistence, upload limits, server security, PDF extraction, error UX, sidebar search, Ollama abort, Web Search prompt injection, Web Search sources, and PDF upload preparation.
- Passed local Web Search/SearXNG packaging and runtime smoke checks.

### Removed
- Removed the local authentication record from the working tree so the user password is not kept locally or tracked.
- Confirmed the active local database files remain outside GitHub and temporary upload, voice, and SearXNG runtime directories are clean.
- Confirmed third-party runtime/vendor payloads, including Whisper, SearXNG, KaTeX, Python runtime files, local models, and PDF libraries, remain out of GitHub.
